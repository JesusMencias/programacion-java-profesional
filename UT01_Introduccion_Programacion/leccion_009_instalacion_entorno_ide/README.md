## 📌 Contenido Técnico
- Validación CLI del entorno: `java -version` y `javac -version`.
- Configuración de variables del sistema: `JAVA_HOME` (directorio raíz) y `PATH` (`%JAVA_HOME%\bin`).
- Prevención y solución del error `java.lang.UnsupportedClassVersionError` (discrepancia de clases compiladas en Java 21).
- Configuración del SDK y Language Level en el IDE (IntelliJ IDEA / VS Code).
