## 📌 Contenido Técnico
- Desglose de la firma: `public static void main(String[] args)`.
- Contrato de reflexión de la JVM y prevención del `NoSuchMethodError`.
- Procesamiento defensivo de argumentos CLI (`args.length`) frente a `ArrayIndexOutOfBoundsException`.
- Reasignación de referencias en Heap y recolección de basura (Garbage Collection).
