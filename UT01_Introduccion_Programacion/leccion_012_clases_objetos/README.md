## 📚 Tratado Teórico y Pedagógico

Hasta este punto, el desarrollo se ha enfocado en la programación estructurada basada en procedimientos y funciones estáticas. Sin embargo, los sistemas de software de nivel industrial exigen modelar entidades del mundo real que poseen propiedades intrínsecas y comportamientos asociados. Para abordar esta complejidad, la ingeniería de software utiliza el paradigma de la **Programación Orientada a Objetos (POO)**.

Java es un lenguaje puramente orientado a objetos y se sustenta sobre dos conceptos fundacionales indivisibles:

**1. La Clase (`class`)**
Una clase funciona como un plano arquitectónico, un molde o una abstracción lógica de alto nivel. Agrupa dos componentes esenciales: los **atributos** (variables que representan el estado) y los **métodos** (funciones que representan el comportamiento).

**2. El Objeto (Instancia)**
Un objeto es una materialización concreta y física de una clase en la memoria RAM del sistema. Cada objeto posee una identidad única, un estado particular y un comportamiento compartido dictado por su clase molde. Se instancian mediante el operador de asignación dinámica `new`.
