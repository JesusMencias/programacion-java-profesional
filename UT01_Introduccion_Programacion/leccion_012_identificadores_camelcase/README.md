## 📚 Tratado Teórico y Pedagógico

En la ingeniería de software, un **identificador** es el nombre simbólico que otorgamos a las variables, métodos y clases. Su sintaxis está regulada por estrictas normas lógicas.

**1. Reglas Sintácticas**
* Admiten letras, números (excepto al inicio), guiones bajos y símbolos de dólar.
* No pueden coincidir con **palabras reservadas** del lenguaje (`public`, `int`, etc.).
* Java es estrictamente *case-sensitive* (diferencia mayúsculas de minúsculas).

**2. Estándar camelCase**
Para mantener legibilidad profesional, las variables y métodos emplean *Lower Camel Case*: la primera palabra en minúscula y las siguientes con inicial en mayúscula (`saldoCuentaBancaria`).
