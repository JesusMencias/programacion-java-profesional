## 📚 Tratado Teórico y Pedagógico

A nivel de hardware, los ordenadores operan con impulsos binarios. Para facilitar el desarrollo, Java permite expresar valores numéricos en cuatro bases principales mediante literales prefijados.

**1. Decimal (Base 10)**
Sistema estándar humano sin prefijos adicionales (`42`).

**2. Binario (Base 2)**
Representación directa de bits empleando el prefijo **`0b`** o **`0B`** (`0b1010`).

**3. Octal (Base 8)**
Agrupación binaria empleando un **cero inicial** como marcador (`052`).

**4. Hexadecimal (Base 16)**
Estándar compacto para mapas de memoria y bytes utilizando el prefijo **`0x`** o **`0X`** junto con dígitos y letras de la A a la F (`0x2A`).
