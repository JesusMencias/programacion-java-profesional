## 📚 Tratado Teórico y Pedagógico

Los operadores son símbolos especiales que indican al compilador que realice operaciones específicas sobre una o más variables o literales, conocidos como operandos. En la ingeniería de software con Java, la correcta manipulación de estos elementos determina la precisión del flujo de control y el cálculo algorítmico.

Java clasifica sus operadores principales en cuatro grandes categorías funcionales:

**1. Operadores Aritméticos**
Permiten ejecutar cálculos matemáticos básicos. Incluyen la suma (`+`), resta (`-`), multiplicación (`*`), división (`/`) y el operador de módulo (`%`), el cual calcula el resto entero de una división y resulta fundamental para determinar paridad o intervalos cíclicos.

**2. Operadores Relacionales y de Comparación**
Evalúan la relación entre dos operandos, arrojando siempre un resultado booleano (`true` o `false`). Comprenden la igualdad (`==`), desigualdad (`!=`), menor que (`<`), mayor que (`>`), menor o igual que (`<=`) y mayor o igual que (`>=`).

**3. Operadores Lógicos**
Diseñados para combinar expresiones booleanas. Destacan el operador AND lógico (`&&`), el OR lógico (`||`), y el NOT lógico (`!`). Los operadores binarios lógicos implementan evaluación de cortocircuito (*short-circuit evaluation*).

**4. Operadores de Asignación e Incremento**
Además de la asignación simple (`=`), Java permite operadores compuestos como `+=`, `-=`, así como los operadores unarios de incremento (`++`) y decremento (`--`).
