## 📚 Tratado Teórico y Pedagógico

La historia de Java es uno de los hitos más influyentes en la evolución de la ingeniería de software moderna. Su diseño resolvió la fragmentación del hardware mediante la portabilidad universal.

**1. Los Orígenes: El Proyecto Green y "Oak"**
A principios de los 90 (1991), un equipo en **Sun Microsystems** liderado por **James Gosling** (*Green Team*) desarrolló un lenguaje para electrodomésticos inteligentes llamado originalmente **Oak** (Roble).

**2. El Salto a la Web y el Lanzamiento (1995)**
En 1994 el proyecto fue redirigido hacia internet, adaptándose para entornos web seguros y renombrándose como **Java**. En mayo de 1995 se lanzó públicamente con la promesa del **Write Once, Run Anywhere (WORA)**.

**3. El Pilar del WORA**
El código fuente (`.java`) se compila a un formato intermedio abstracto llamado **Bytecode** (`.class`). La Máquina Virtual de Java (JVM), implementada de forma nativa en cada sistema operativo, traduce ese Bytecode a instrucciones de hardware locales en tiempo real, garantizando ejecución idéntica en cualquier plataforma.
