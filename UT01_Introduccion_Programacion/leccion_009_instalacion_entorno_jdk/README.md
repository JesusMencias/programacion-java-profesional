## 📚 Tratado Teórico y Pedagógico

Para transformar conceptos lógicos en software ejecutable, el ingeniero requiere un puesto de trabajo configurado bajo estándares industriales estrictos.

**1. Selección del Kit de Desarrollo: JDK 21 LTS**
El estándar **LTS** (*Long-Term Support*) garantiza estabilidad, parches de seguridad prolongados y compatibilidad corporativa, siendo obligatorio en el desarrollo profesional de Java.

**2. Variables de Entorno (`JAVA_HOME` y `PATH`)**
* **`JAVA_HOME`:** Variable global que apunta al directorio raíz del JDK instalado.
* **`PATH`:** Registro que incluye `%JAVA_HOME%\bin` para permitir la ejecución de los binarios del compilador desde cualquier terminal.

**3. El Entorno de Desarrollo (IDE)**
Plataforma integral (como IntelliJ IDEA) que centraliza la edición de código, compilación, depuración visual (*debugger*) y control de versiones.
