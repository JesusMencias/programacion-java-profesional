## 📌 Arquitectura Base
- **JDK:** Java Development Kit (incluye `javac`, herramientas y JRE).
- **JRE:** Java Runtime Environment (entorno para ejecutar).
- **JVM:** Java Virtual Machine (ejecuta Bytecode en hardware nativo).
